# Backhaul Testing

We're validating a higher-bandwidth **500 kHz** backhaul tier for the PugetMesh MeshCore network — *more bandwidth, fewer retransmissions, faster propagation*. See **[RF Bridge &amp; Backhaul](../rf_bridge.md)** for the background on why 500 kHz and how an RF bridge joins it to the local 62.5 kHz mesh.

Each test runs on the live mesh; where a test touches a repeater we coordinate in the [backhaul-testing Discord channel](https://discord.com/channels/1291139029814739084/1549925039388885033).

- **[Test1 — 500 kHz backhaul trial](test1.md)** — Sept 11–15, 2026 (completed)
- **[Test2 — 500 kHz spectrum test](test2.md)** — Sept 19–20, 2026
- **[Test3 — modified frequency, SF, and CR](test3.md)** — Sep 21–22, 2026 (48 hours)
